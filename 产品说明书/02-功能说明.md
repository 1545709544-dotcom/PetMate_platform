# 02 · 功能说明

> 全面介绍 PetMate 的功能模块。本章按业务域组织,每项功能从"客户能做什么"和"系统做了什么"两个角度描述。

---

## 角色与权限

PetMate 内有三类顶层角色,每个角色下还有更细的子账户。

| 顶层 | 子账户 | 说明 |
| :--- | :--- | :--- |
| **普通用户** | 游客 | 未登录可浏览,不能写 |
| | 注册用户 | 默认账户,完整功能 |
| | VIP 用户 | 年消费达到门槛,享折扣与专属客服 |
| **商家** | 店长 | 主账号,所有权限 |
| | 店员 | 处理订单、上架商品 |
| | 技师 | 美容/训练服务提供者 |
| **平台管理员** | 运营 | 配置活动与内容 |
| | 客服 | 处理退款、举报、纠纷 |
| | 财务 | 结算、账单查看 |
| | 超管 | 一切权限,含角色分配 |

权限粒度覆盖到每一个接口与按钮。例如普通用户不能访问商家后台,店员不能修改店铺基础信息,只有店长和超管可以分配角色。

## 模块一:用户中心

### 1.1 注册与登录

支持的登录方式:

- **手机号 + 密码登录**:推荐方式,适合已注册用户
- **手机号 + 短信验证码**:演示环境验证码固定为 `123456`
- **微信扫码登录**:适合手机端,授权后自动建账

> 登录后服务端签发令牌,有效期 7 天,活跃操作自动续期,不必频繁重新登录。

### 1.2 个人资料

可维护的字段:

- 头像(支持 AI 卡通头像生成)
- 昵称、性别、生日、所在地区
- 个性签名

### 1.3 收货地址

- 增删改查,最多保存 20 个地址
- 支持设置"默认地址",下单时自动带入
- 地址录入时自动解析省/市/区,无需手动选择

### 1.4 会员等级

- 等级 V0–V5,按近 12 个月消费额自动升级
- 等级权益:购物折扣、问诊配额翻倍、专属客服入口
- VIP 续费/开通在 `/vip/open` 页面

## 模块二:宠物档案

每位用户可绑定多只宠物,每只宠物拥有独立档案。

### 2.1 基础信息

- 名字、品种(覆盖 200+ 标准品种)、性别、出生日期
- 体重、绝育情况、芯片号

### 2.2 健康档案

按时间线记录:

- 体重变化
- 疫苗接种(下一次到期自动提醒)
- 驱虫周期
- 体检报告
- 既往病史

### 2.3 成长日记

- 图文混排,每篇支持 1–9 张图片
- 标签 + 心情 + 纪念日
- 可设公开/仅自己可见

### 2.4 智能提醒

- 疫苗到期前 7 天站内消息推送
- 驱虫周期到达时提醒
- 年度体检到期提醒

## 模块三:商品商城

### 3.1 分类树

三级分类:大类(如"食品")→ 中类(如"猫粮")→ 小类(如"幼猫粮")。分类支持图标与 banner 运营位。

### 3.2 商品详情

- 富文本详情(图片 + 文字)
- 多规格(SKU)选择
- 评价列表 + 商家回复
- "看了又看"推荐位
- 一键收藏、加入购物车

### 3.3 商品搜索

- 关键词全文检索,支持中文分词
- 关键词高亮显示
- 按销量、价格、评价等多维度筛选与排序

### 3.4 评价系统

- 1–5 星评分
- 图片 + 文字评价
- 商家可公开回复
- 平台抽审,违规评价会被折叠

### 3.5 收藏与足迹

- "我的收藏"集中管理感兴趣的商品
- "我的足迹"自动记录浏览历史
- 行为数据用于推荐系统持续优化首页

## 模块四:购物车与订单

### 4.1 购物车

- 登录态在服务端持久化,多端同步
- 游客态存在本地浏览器,登录后自动合并
- 实时显示库存与价格变化

### 4.2 下单流程

四步走:地址确认 → 优惠券选择 → 支付方式选择 → 提交订单

### 4.3 订单状态机

订单在生命周期内有明确的状态流转:

| 状态 | 进入条件 | 退出条件 |
| :--- | :--- | :--- |
| 待支付 | 提交订单 | 支付成功 / 超时取消 / 用户取消 |
| 待发货 | 支付成功 | 商家发货 / 申请退款 |
| 已发货 | 商家发货 | 确认收货 / 7 天自动收货 / 申请退货 |
| 退款中 | 申请退款或退货 | 客服审核完成 |
| 已完成 | 确认收货 | 终态 |
| 已取消 | 超时或主动取消 | 终态 |
| 退款成功 | 客服审核通过 | 终态 |

### 4.4 发票申请

- 订单完成后可申请电子发票
- 支持填写公司抬头与税号
- 申请后由商家开具,站内消息通知

## 模块五:支付与钱包

### 5.1 支付方式

- 微信支付(沙箱)
- 支付宝(沙箱)
- 平台余额(模拟支付)

> 演示环境使用沙箱,不发生真实资金流;生产环境需对接真实支付通道。

### 5.2 优惠券

三种类型:满减券 / 折扣券 / 品类券

- 领券中心定期发放
- 下单时自动筛选可用券
- 核销 0 资损,退款时按比例退回

### 5.3 余额充值

- 演示态可模拟充值
- 余额可支付订单,也可提现(走客服)

### 5.4 退款

- 原路退回,余额部分即时到账
- 退款的处理时效:普通订单 1–3 个工作日,售后单最长 7 个工作日

## 模块六:AI 智能问诊 ★

### 6.1 入口

- 首页右下角悬浮按钮
- 宠物档案页"问健康"按钮

### 6.2 形态

多轮对话,聊天气泡式,类似主流 AI 助手。

### 6.3 输入

- 文字描述
- 语音输入(基于语音识别服务)
- 图片上传(支持拍照上传体征照片,例如皮肤红疹)

### 6.4 输出

- **分级建议**:紧急 / 建议就医 / 日常照护
- 解释"为什么这样判断"
- 关联商品推荐(例:推荐皮肤喷剂)
- 紧急情况提示最近宠物医院

### 6.5 兜底机制

AI 无法确诊时,会明确提示"建议尽快就医",不会给出误导性结论。

## 模块七:美容洗护与训练课程

### 7.1 美容洗护

- 选择门店
- 选择技师(查看其历史评分与作品)
- 选择套餐(洗澡、修剪、SPA 等)
- 选择时段

### 7.2 训练课程

- 视频课(点播,按课程包购买)
- 1v1 私教(按课时购买,可指定教练)

### 7.3 上门与到店

以到店为主,部分城市提供上门服务,在地图上选点与时段。

## 模块八:寄养托管

### 8.1 两种模式

- **家庭寄养**:寄养在经验丰富的爱宠家庭,环境舒适
- **宠物店寄养**:专业笼位与值班人员

### 8.2 寄养家庭展示

- 实景图片与视频
- 历史评价
- 价格透明,无隐藏收费
- 联系方式可一键发起咨询

### 8.3 寄养期间

- 每日视频打卡,主人可查看
- 实时位置(受邀可见)
- 主人可与寄养家庭文字沟通

### 8.4 接回流程

签离 → 评价 → 平台抽佣结算。整个过程有电子记录,纠纷可追溯。

## 模块九:社区动态

### 9.1 发布

- 图文 / 短视频(时长 ≤ 30 秒)
- 话题标签(自动聚合到话题广场)
- @好友(站内消息通知)
- 关联宠物档案

### 9.2 互动

- 点赞、评论、收藏、分享
- 关注作者,看 Ta 的后续动态

### 9.3 推荐

首页 feed 是千人千面的,根据用户兴趣推荐。热门话题榜单独页面。

### 9.4 审核

- AI 初审:涉黄涉政等敏感词自动拦截
- 人工抽审:运营对可疑内容复核
- 用户可一键举报

## 模块十:领养救助

### 10.1 送养信息

- 免费发布送养,需平台审核
- 填写宠物基本信息、来源、健康状况

### 10.2 领养协议

- 在线签署电子协议
- 平台留存电子签名,具备法律效力

### 10.3 回访

- 领养后 7/30/90 天自动推送回访问卷
- 跟踪领养情况,保障宠物福利

## 模块十一:知识科普

### 11.1 内容

- 平台官方与签约作者发布
- 富文本 + 多媒体(图片、视频)
- 按宠物种类 + 主题(健康/喂养/行为/心理)分类

### 11.2 SEO 友好

- URL 形如 `/knowledge/cat/health/vaccine`,便于搜索引擎收录
- 详情页有"相关推荐"自动串联

### 11.3 收藏与点赞

行为数据回流推荐系统,让优质内容获得更多曝光。

## 模块十五:推荐系统 ★

首页 feed 是 PetMate 的差异化亮点之一。

### 15.1 工作原理

系统综合三类信号:

- **用户行为**:浏览、收藏、加购、购买
- **宠物画像**:品种、年龄、健康状况
- **内容相似**:商品之间的相似度,内容之间的相似度

### 15.2 推荐位

- 首页 feed:千人千面的混合流(图文/商品/服务)
- 商品详情"看了又看"
- 订单完成"买了又买"
- 服务页"附近 + 兴趣加权"

### 15.3 冷启动

新用户没有行为数据时,系统先展示热门内容,引导用户完善宠物档案与兴趣偏好,之后逐步切换为个性化推荐。

## 配套服务

### 客服与申诉

- 站内"我的消息"接收系统通知
- 订单纠纷、退款争议可走"申请平台介入"
- 工作日 9:00–18:00 客服在线

### 数据与隐私

- 个人资料仅用户本人与授权商家可见
- 支付信息走支付通道,平台不存储完整卡号
- 行为数据用于推荐优化,客户可在"隐私设置"中关闭个性化推荐
