# 01 · 产品介绍

> 了解 PetMate 是谁、它要解决什么问题,以及为何选择我们。

---

## 一、我们是谁

PetMate(读作"宠物伴侣")是一款面向都市宠物主的**一站式智能养宠服务平台**。我们把与"养好一只宠物"相关的所有事务——买粮、看病、寄养、社交、学知识、领养救助——整合到同一个 Web 端入口,让宠物主不必再在多个 App 之间来回切换。

平台同时为宠物门店、医院、寄养家庭、技师等**商家**提供数字化工作台,并为平台运营方提供管理后台与数据看板,形成一个"宠物 + 人 + 服务"三方共赢的数字生态。

## 二、我们要解决的问题

随着都市独居、晚婚晚育率上升,宠物已成为很多家庭的重要成员。但目前市面上的宠物服务普遍存在以下问题:

| 客户痛点 | 实际表现 |
| :--- | :--- |
| **服务分散** | 买粮去一个 App、看病去另一个 App、寄养找闲鱼,需要在 5+ 个应用间切换 |
| **内容不专业** | 社区里的养宠知识良莠不齐,新手宠主难以分辨真伪 |
| **夜间无助** | 深夜宠物突发状况,找不到人咨询,只能在搜索引擎里碰运气 |
| **商家获客难** | 宠物门店依赖点评与线下,缺乏数字化工具与持续曝光 |
| **触达不精准** | 推荐内容千篇一律,无法根据宠物品种、年龄给出针对性建议 |

PetMate 的出现,正是为了让这些问题在一处得到系统性解决。

## 三、我们提供什么

PetMate 的能力可以归纳为**五大场景**:

### 1. 一站式购物

食品、用品、药品、玩具、服饰一次购齐,跨品类挑选、统一结算、统一售后。

### 2. 专业服务直约

美容洗护、训练课程、寄养托管、上门遛狗等本地生活服务,在线挑选、比价、预约,像订餐厅一样方便。

### 3. AI 健康陪伴 7×24

基于大语言模型打造的"AI 健康师",遇到紧急情况给方向,日常给科普,免去深夜焦虑。

### 4. 同好社区

发布图文动态、晒萌照、关注同好、加入话题,形成养宠的情感归属。

### 5. 千人千面推荐

根据宠物档案、浏览记录、购买行为,首页 feed 自动调整,让"你可能喜欢"真的"你喜欢"。

我们服务的客户主要分为五类:

| 客户类型 | 占比 | 典型场景 | 关键需求 |
| :--- | :---: | :--- | :--- |
| 都市年轻宠主 | 60% | 上下班通勤、深夜突发、节假日出行 | 便捷购药、AI 问诊、社区分享 |
| 新手宠主 | 20% | 第一只宠物,知识空白 | 系统化科普、训练课、疫苗提醒 |

| 平台运营与客服 | 2% | 内容审核、风控、活动配置 | 管理后台 + 数据看板 |

| 价值 | 给客户带来的实际收益 |
| :--- | :--- |

| **个性化** | 首页推荐根据宠物档案和行为持续优化 |

## 六、为何选择 PetMate

- **完整的业务闭环**:从"想买"到"已评价",所有环节在站内完成
- **真实的个性化**:推荐系统基于协同过滤,不是简单按销量排序
- **AI 真有产出**:AI 健康师不仅给结论,还按紧急程度分级,并推荐相关药品
- **商家可被找到**:服务页"附近 + 兴趣加权",本地商家有公平的曝光机会
- **响应式体验**:一套 Web 代码,桌面、平板、手机浏览器都好用,不需要下载多个客户端

## 七、用户角色概览

PetMate 内有 **三类顶层角色**,分别在不同的入口完成各自的工作:

| 角色 | 入口 | 典型任务 |
| :--- | :--- | :--- |
| **普通用户(含游客)** | 主站 `/` | 购物、问诊、社交、领养 |
| **商家** | `/merchant/dashboard` | 接单、上架、数据复盘 |
| **平台管理员** | `/admin/dashboard` | 用户管理、内容审核、数据看板 |

三类角色通过不同的登录入口进入,看到的界面与可执行的操作完全不同。详细权限见 [02-功能说明](./02-功能说明.md) 中的"角色与权限"章节。

## 八、产品发展原则

我们坚持以下几点原则,贯穿产品演进全过程:

1. **客户价值优先** —— 不为了技术炫技而堆功能,每个新能力都先问"对客户有什么具体帮助"
2. **数据透明** —— 推荐逻辑、商家评分、订单状态都尽量可解释
3. **可信赖** —— AI 不替代兽医的最终判断,只给方向;商家资质有审核机制
4. **可持续** —— 商家侧有清晰的结算与分账规则,平台不靠"套路"做生意
