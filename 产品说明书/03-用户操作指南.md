# 03 · 用户操作指南

> 通过 9 个典型场景,演示如何用 PetMate 完成常见任务。每一步都说明"在哪个页面"和"做什么操作"。

---

## 通用说明

- **入口地址**:浏览器访问主站,根据身份选择对应入口
  - 普通用户:`/`(主站首页)
  - 商家:`/merchant`(商家后台)
  - 平台管理员:`/admin`(管理后台)
- **演示账号**:`13800138000` / `123456`(普通用户)
- **响应式**:同一套页面在桌面、平板、手机浏览器都可用,推荐 Chrome / Edge / Safari 最新版

---

## 场景 1:注册与登录

### 1.1 用手机号注册

1. 打开主站 `/`
2. 点击右上角 **"注册"** 按钮
3. 输入手机号,获取验证码(演示环境固定为 `123456`)
4. 设置登录密码(至少 6 位)
5. 点击 **"注册"** 完成,自动登录

### 1.2 用账号密码登录

1. 打开 `/login`
2. 选择"密码登录"标签
3. 输入手机号与密码
4. 点击 **"登录"**

### 1.3 切换登录入口

- 普通用户去 `/login`
- 商家去 `/merchant`(演示态直接进入)
- 管理员去 `/admin/login`

---

## 场景 2:添加宠物档案

1. 登录后,进入 **"我的" → 宠物档案**
2. 点击 **"+ 添加宠物"**
3. 填写基本信息
   - 名字(必填)
   - 品种(从 200+ 标准品种中选择)
   - 性别、生日、是否绝育
   - 体重(选填,后续可在健康档案中持续更新)
4. 上传头像(可选,支持 AI 卡通头像)
5. 点击 **"保存"** 完成

**后续如何更新档案?**

- 进入"宠物详情"页,点击右上角 **"编辑"** 即可修改
- 添加疫苗、驱虫、体检等记录,在"健康档案"标签页操作

---

## 场景 3:购买商品

### 3.1 找到想买的商品

有三种方式:

- **首页浏览**:首页 feed 包含商品推荐,点开查看详情
- **分类查找**:顶部菜单"分类"→ 选择品类 → 浏览列表
- **关键词搜索**:顶部搜索框输入关键词,如"猫粮""磨牙棒"

### 3.2 加入购物车

1. 在商品详情页选择规格(例:1kg / 5kg)
2. 点击 **"加入购物车"**
3. 购物车图标右上角出现数量提示

### 3.3 提交订单

1. 进入 **"购物车"**
2. 勾选要结算的商品
3. 点击 **"去结算"**
4. 确认收货地址(可临时修改或新增)
5. 选择优惠券(可用券会自动列出)
6. 选择支付方式
7. 点击 **"提交订单"**

### 3.4 完成支付

- 选择"微信支付"会拉起支付二维码
- 选择"支付宝"会跳转到支付宝
- 选择"余额支付"会直接从账户余额扣款
- 支付成功后自动跳转到订单详情

### 3.5 查看物流

- 在 **"我的订单"** 找到对应订单
- 点击进入"订单详情"
- 已发货订单会显示快递公司与单号
- 点击单号可跳转物流跟踪

## 场景 4:使用 AI 智能问诊

### 4.1 发起问诊

1. 点击首页右下角 **悬浮"AI 问诊"按钮**
   (或在宠物档案页点击"问健康")
2. 在对话框输入问题,例如"我家猫咪最近总打喷嚏,流清水鼻涕"
3. AI 会追问关键信息(年龄、最近是否受凉、有没有其他症状)

### 4.2 上传图片(可选)

- 如果有体征照片(皮疹、伤口等),点击输入框旁的"图片"图标
- 拍照或从相册选择
- AI 会结合图片一起判断

### 4.3 查看建议

AI 会给出:

- 紧急程度评级(紧急 / 建议就医 / 日常照护)
- 判断依据
- 家庭护理建议
- 关联商品推荐(可一键加入购物车)

### 4.4 紧急情况

- 提示"紧急"时,会主动推荐最近的宠物医院
- AI 不会替代兽医的最终诊断,涉及急症请尽快就医

### 4.5 查看历史

所有问诊会话可在 **"我的 → 问诊历史"** 中找到,方便回看。

## 场景 5:预约美容洗护

1. 顶部菜单 **"服务"** → 美容洗护
2. 选择城市(自动定位,可手动切换)
3. 浏览附近门店,看实景、评分、价格
4. 点击进入门店详情,选择 **"立即预约"**
5. 选择服务项目(例:基础洗澡、精致造型)
6. 选择技师(可看技师作品与评分)
7. 选择日期与具体时段
8. 选择上门/到店,确认宠物档案
9. 确认订单并支付(支持使用优惠券)
10. 预约成功后,到店核销或等待师傅上门

---

## 场景 6:寄养宠物

1. **"服务"** → 寄养托管
2. 浏览寄养家庭/宠物店
3. 重点关注:实景视频、历史评价、寄养经验
4. 点击 **"联系商家"** 预沟通
5. 选定后,选择寄养起止日期
6. 确认寄养协议(电子签字)
7. 完成支付
8. 寄养期间每天可查看视频打卡
9. 寄养结束,签离并对寄养家庭评价

---

## 场景 7:发布与互动社区动态

### 7.1 发布动态

1. 底部导航(手机端)或顶部菜单(桌面端)点击 **"+"** 或 **"发布"**
2. 选择发布类型:图文 / 短视频
3. 上传素材(图片最多 9 张,视频 ≤ 30 秒)
4. 撰写文字内容
5. 添加话题标签(例:#金毛日常)
6. 关联宠物档案(可选,便于推荐)
7. 点击 **"发布"**

### 7.2 互动

- 在首页 feed 或话题广场浏览动态
- 点击 **"❤"** 点赞
- 点击 **"评论"** 输入回复
- 点击 **"关注"** 关注作者
- 点击 **"分享"** 复制链接或生成海报

---

## 场景 8:领养一只宠物

1. **"领养"** → 浏览可领养宠物
2. 通过筛选条件(地区/品种/年龄)缩小范围
3. 点击进入详情,看宠物介绍、健康状况、来源
4. 点击 **"申请领养"**
5. 填写领养问卷(养宠经验、家庭环境等)
6. 等待送养方审核(通常 1–3 天)
7. 审核通过后,签署电子领养协议
8. 约定接宠时间
9. 领养后 7/30/90 天会收到回访问卷,请按时填写

---

## 场景 9:退款与售后

### 9.1 申请退款

1. 在 **"我的订单"** 找到目标订单
2. 点击 **"申请退款"**
3. 选择退款原因(不喜欢/质量问题/其他)
4. 上传凭证(图片)
5. 填写退款金额(默认全额)
6. 提交申请

### 9.2 等待处理

- 商家会在 24 小时内响应
- 若商家同意,自动退款到原支付方式
- 若商家拒绝,可申请平台客服介入

### 9.3 申请平台介入

1. 在退款单详情点击 **"申请客服介入"**
2. 补充说明与凭证
3. 平台客服会在 1–3 个工作日内给出处理结果

## 商家端操作(简要)

商家操作集中在 `/merchant` 下,以下是高频任务:

| 任务 | 操作路径 |
| :--- | :--- |
| 处理订单 | 工作台 → 待办 → 订单详情 → 发货 |
| 上架商品 | 商品管理 → 新增商品 → 填写信息 → 提交审核 |
| 设置排班 | 服务管理 → 排班 → 选择日期与时段 |
| 查看销售 | 数据 → 销售看板 |
| 处理退款 | 退款管理 → 选择退款单 → 同意/拒绝 |
| 回复评价 | 评价管理 → 选择评价 → 回复 |

完整商家操作手册将在 [04-技术架构说明](./04-技术架构说明.md) 附录中以独立文档提供。

## 管理端操作(简要)

平台管理员操作集中在 `/admin` 下:

| 任务 | 操作路径 |
| :--- | :--- |
| 审核商家入驻 | 商家管理 → 入驻审核 |
| 审核动态内容 | 内容审核 → 社区 |
| 监控平台数据 | 仪表盘 |
| 配置活动 | 营销 → 秒杀/优惠券 |
| 处理用户举报 | 风控 → 举报中心 |
| 维护敏感词 | 风控 → 敏感词库 |
