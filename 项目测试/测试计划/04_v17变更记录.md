## 2. 修复 6 项致命安全缺陷

### 2.1 R3.6 — JWT 密钥明文（关键）
- `application.yml:46` → `secret: ${PETMATE_JWT_SECRET:dev-default-secret-please-change-in-production-must-be-32-bytes-minimum-length}`
- `.env` 追加 `PETMATE_JWT_SECRET=dev-jwt-secret-change-me-this-is-only-for-local-development-32bytes-min`
- 3 个启动脚本（`start-backend.bat` / `start-backend-test-demo.bat` / `start-backend-test-bypass.bat`）追加 `-DPETMATE_JWT_SECRET=%PETMATE_JWT_SECRET%`
- **新建** `.env.example`（**仓库原本不存在**）作为模板

### 2.2 R3.7 / R3.8 — 封禁生效（关键）
- `security/JwtAuthFilter.java` 状态注入分两路：
  - admin / merchant-店主：`SELECT status FROM t_user WHERE id=? AND is_deleted=0`
  - merchant-员工：`SELECT status FROM t_merchant_staff WHERE id=?`，把 `1=启用 / 0=停用` 映射为 `userStatus 0=正常 / 1=封禁`
- `security/JwtAuthFilter.java` 增加 `blacklist.userRevoked(uid)` 检查（管理员封禁账号触发全员下线）
- 12 处 Controller 调用点从 `requireRole(...)` 升级为 `requireRoleAndActive(...)`：
  - 5 个 admin 文件：`AdminController` / `AdminConfigController` / `BannerController` / `AnnouncementController` / `ReportController`(3 处) / `AdminAdoptionController`
  - 6 个 merchant 文件：`MerchantController` / `MerchantOpsController` / `MerchantStaffController` / `MerchantNotificationController` / `MerchantAppointmentController`

### 2.3 R3.13 / R3.14 — TokenBlacklist 持久化（关键）
- **新建** `sql/migrate_v17.sql`：新增 `t_token_blacklist` 表（jti PK / user_id / exp_at / reason）+ 补齐 `t_merchant_staff` DDL
- `security/TokenBlacklist.java` 重写：Caffeine 缓存（30s TTL, max 50k）+ JdbcTemplate 持久化 + 按 userId 全员撤销（`revokeByUser`）
- `auth/AuthController.java#logout` 升级为 4 参签名 `revoke(jti, exp, uid, "logout")`

### 2.4 R3.11 — 入驻信息泄露（关键）
- `merchant/MerchantApplyController.status()` 加 `TokenContext.requireUserId()` + `phone == 当前用户手机` 校验
- 不通过抛 `NO_PERMISSION`

### 2.5 R2.1 — 公钥未配置拒验证（关键）
- `pay/AlipayClient.verifyNotify` `return true` → `return false`（fail-closed）+ ERROR 日志

### 2.6 R2.2 — TLS 校验默认安全（关键）
- `pay/AlipayProperties` 新增 `insecure` 字段（默认 false）
- `pay/AlipayClient` 拆分为 `buildDefaultClient()`（JDK 系统证书）+ `buildInsecureClient()`（仅 sandbox 应急）
- `application.yml` 新增 `alipay.insecure: ${ALIPAY_INSECURE:false}`
- `start-backend-test-bypass.bat` 同步新增 `-DALIPAY_INSECURE=true`
